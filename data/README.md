# ACAPS data

This demo ships with **only an embedded R1043 fallback record** to run offline.

To show all **139 organizer-supplied risks**, obtain the official cleaned data from:

https://github.com/Hackathon-for-Good-The-Hague/HFG8-ACAPS-Ground-Truth/tree/main/data

Copy `risk-radar-export.csv` into this directory. Restart the server; it will automatically load the CSV. Do not modify the source data without noting changes. The CSV remains subject to ACAPS' applicable terms of use.

The *forecast question* and five expert submissions in this prototype are **synthetic author-created demo content**, not official ACAPS forecasts or field testimony.
