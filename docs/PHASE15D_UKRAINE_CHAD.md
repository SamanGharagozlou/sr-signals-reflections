# Phase 15D: Ukraine Country Zoom + Chad Expert Invitation

## Intended product flow

- **Analyse** has a new entry point to `/ukraine-zoom`, a real interactive React page with administrative-region selection, 26 fictional weekly values, five map layers, a trend chart and a computed regional correlation matrix.
- **Share** has a static public-safe invitation to the pre-existing synthetic Chad expert consultation (`/expert`). The invitation does **not** depend on publication approval or contain private aggregates.
- The existing Share report remains gated behind `api.getPublicSummary().approved` and its backend enforcement. No existing permissions, APIs, or database endpoints are modified.

## Important data boundaries

- Ukraine ADM1 geometry is downloaded from a pinned **geoBoundaries** `gbOpen` snapshot, which references **2017** administrative areas and originates from OpenStreetMap / Wambacher. It is *not* a current territorial-control layer, a claim about sovereignty disputes, or a live operational geospatial picture.
- Underlying geometry license: **Open Database License (ODbL) 1.0**, © OpenStreetMap contributors, via geoBoundaries. Preserve attribution and comply with ODbL obligations if redistributing a derived boundary database. API metadata: https://www.geoboundaries.org/api/current/gbOpen/UKR/ADM1/ ; license https://www.openstreetmap.org/copyright .
- 26-week risk scores, thematic scenario groups (front-line, energy, displacement), numeric correlations, trend trajectories and co-movement comparisons are **entirely deterministic fictional demonstrations** with no operational or official ACAPS status.
- Chad's expert consultation uses the pre-existing fictional R1043 workflow; this patch adds only public-safe navigation and explanatory text.
- No local `data/` CSV or JSON, backend files, authorization gates, source normalization or forecast results are modified.

## Live acceptance test

1. `/analysis`: check that **Ukraine country zoom** entry appears. Open `/ukraine-zoom`.
2. Confirm the regional map loads with 20–35 regions and the historical geometry notice.
3. Select two different regions on the map, in the selector, and by keyboard. Their trend, rankings, and matrix must update.
4. Change all five map modes; returned values should remain internally consistent with the synthetic 26-week series.
5. Open `/public` in a new unprivileged session: the Chad expert invite must appear; no unpublished panel summaries should leak.
6. Open expert contribution and confirm the existing role/consultation process (synthetic data only).
7. An authenticated moderator can complete the approval workflow; only afterwards may `/public` show the approved public aggregate.
8. Check mobile layout and browser console, plus `python -m unittest discover -s tests -q`, `bun run test`, `bun run build`, and release preflight.
